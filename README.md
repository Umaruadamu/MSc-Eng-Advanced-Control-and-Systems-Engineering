MSc (Eng) – Advanced Control & Systems Engineering

University of Sheffield | 2016

Systems Engineering Foundation for Intelligent Cybersecurity

This programme provided advanced training in control theory, distributed systems, and industrial automation, establishing the systems-engineering foundation that underpins my subsequent research in AI-driven cybersecurity and intelligent threat detection frameworks.

Technical Foundations

System Modelling & Identification – Mathematical modelling of dynamic systems from experimental data, supporting data-driven system analysis and behavioural modelling approaches later applied in cybersecurity research.

Optimal & Robust Control – Advanced control design methodologies focused on stability, uncertainty management, and system resilience — principles directly relevant to secure and fault-tolerant architectures.This included exposure to Modern Predictive Control (Model Predictive Control – MPC) techniques for constrained optimisation and real-time decision-making in complex systems.

Digital Control Systems – Discrete-time control theory and embedded implementation within industrial and cyber-physical systems.

Industrial Automation – PLC-based automation systems and industrial control architectures, providing early exposure to operational technology (OT) environments and critical infrastructure systems.

Signal Processing – Feature extraction, pattern recognition, and data analysis techniques that informed later work in machine learning–based malware classification.

Security in Networked Systems – Engineering considerations for secure communication and resilience within distributed control systems.
